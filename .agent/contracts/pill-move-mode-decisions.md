# Pill move mode decisions

All three recommendations approved by the user.

1. Should the dropped position persist across app restarts? Recommended: yes, so repositioning only needs to be done once.
2. Should move mode be available during active dictation or speaking? Recommended: defer entry until idle, preserving the current voice session.
3. Should Escape cancel movement and restore the starting position? Recommended: yes, with Enter dropping the pill for keyboard users.
