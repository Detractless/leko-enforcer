### core/src/lib.rs
**Purpose:** Crate root that declares the modules of the Leko Enforcer core library and re-exports its public entry points.
**Feature:** rust-config-core
**Existing code checked:** `grep -rn -e pub -e mod core/src` found nothing, because core/src holds no code yet and this is the first file of the crate.
**Failure paths:** It holds only module declarations and re-exports, so it has no input to fail on; a missing module is a compile error caught by cargo test.
**Criterion:** AC-001: every corpus zip is read or refused as the corpus says (the crate root exposes the zip and settings readers that test uses)

### core/src/io/zip_reader.rs
**Purpose:** Open a settings zip the way the phone's ZipInputStream does and return its files, or the phone's refusal sentence.
**Feature:** rust-config-core
**Existing code checked:** `grep -rn -e inflate -e zip core/src` found nothing, because core/src holds no code yet, so the zip reader must be written new.
**Failure paths:** Empty, truncated, encrypted, over-sized or bomb-like zips and names that are not UTF-8 return a refusal sentence and never panic.
**Criterion:** AC-009: empty, truncated, non-UTF-8 and deeply hostile input is refused, never a panic (the zip layer is the first thing hostile bytes reach)
**Split justification:** Reading zip bytes is a separate responsibility from the crate root, which only declares modules and holds no logic.
