# Active plan: one "### <path>" entry per new code file (format: .agent/plans/TEMPLATE.md)
<!-- contract-required -->
This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### core/src/decision/rule_closes.rs
**Purpose:** Says whether one rule of a block closes at an instant in a time zone: always, every open, outside hours and session; minutes and opens are reported as not judged.
**Feature:** block-decision
**Existing code checked:** `grep -rn -e closes_by_time -e outsideHours -e weekday core/src` shows only the readers, the loosening comparison and the weekday-list reader; nothing judges a rule at an instant, so a new judge is needed.
**Failure paths:** An instant the zone cannot place reads as 1970-01-01 (the zone code's own fallback) and never panics; an empty allowed list closes on every applicable day; a kind this code does not judge is returned as not judged, never as open.
**Criterion:** AC-003: an outsideHours rule closes at every local minute outside its allowed stretches, following the phone's cases across midnight and weekdays

### core/src/decision/block_cover.rs
**Purpose:** Says whether a block covers one app or one website host, after the never-blocked apps are left out and with sites matched only against hosts.
**Feature:** block-decision
**Existing code checked:** `grep -rn -e covers_host -e any_site_covers -e allAppsExcept core/src` shows the site matcher (reused here), the reader and the loosening comparison; nothing answers whether a block covers an app.
**Failure paths:** A block with no apps named and no sites covers nothing; an empty host or app name is covered by nothing; a never-blocked app is never covered, even by an all-except block.
**Criterion:** AC-006: apps, all-except and sites decide what a block covers, and a never-blocked app stays open
**Split justification:** Coverage is a different question from judging a rule at an instant (rule_closes.rs) and from putting the answer together (decide_target.rs); it needs no clock and no zone.

### core/src/decision/decide_target.rs
**Purpose:** Puts together the answer for one target: every closing block and rule in a fixed order, and the rules that count use and are not judged yet.
**Feature:** block-decision
**Existing code checked:** `grep -rn -e decide -e Decision core/src` found nothing, so there is no earlier answer type to extend.
**Failure paths:** Settings with no blocks, only switched-off blocks, or a target nothing covers give an open answer with empty lists; a never-blocked app gets an open answer with nothing listed.
**Criterion:** AC-007: a closed answer lists every closing block and rule in the order of block ids, rules as written
**Split justification:** This file only gathers what rule_closes.rs and block_cover.rs return into one ordered answer; it holds no time or coverage logic of its own.

### core/src/decision/next_change.rs
**Purpose:** Finds the first moment after a given one at which the closing state of any rule of an on block differs, looking eight days ahead by the minute and at every session end.
**Feature:** block-decision
**Existing code checked:** `grep -rn -e next_change -e due_time core/src` shows only due_time.rs, which finds when a loosening may land under lock windows; it does not look at rules, so a separate search is needed.
**Failure paths:** Nothing changing within eight days gives none; a moment so large that the look-ahead would overflow gives none; settings with no blocks give none.
**Criterion:** AC-009: the next change is the first moment the closing state differs, found by the minute for eight days and at each session end
**Split justification:** This is a search over time using rule_closes.rs, while decide_target.rs answers for one moment; the two have different inputs and outputs.
