This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### cli/src/enforcement/macos_applications.rs
**Purpose:** Enumerates macOS running applications and requests their normal termination through AppKit.
**Feature:** macos-app-enforcement
**Existing code checked:** `rg -n NSWorkspace cli/src` shows no existing macOS application adapter.
**Failure paths:** Missing application identities are returned as unidentified; an app that exits or changes identity before termination is not terminated.
**Criterion:** AC-002: closed running instances are requested to terminate.

### cli/src/enforcement/enforcement_loop.rs
**Purpose:** Reloads settings and judges running apps on each enforcement tick.
**Feature:** macos-app-enforcement
**Existing code checked:** `rg -n read_settings_and_bytes cli/src` shows the reusable validated settings reader.
**Failure paths:** Invalid settings retain the last valid settings; failed termination is reported and retried on the next tick.
**Criterion:** AC-004: invalid replacement settings retain the last valid rules.
**Split justification:** AppKit calls and the decision loop have separate responsibilities and can be verified independently.
