This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### cli/src/launch_agent/agent_plist.rs
**Purpose:** Builds and validates the owned launch agent configuration and its exact argument values.
**Feature:** macos-launch-agent
**Existing code checked:** `rg -n launchctl cli/src` shows no launchd plist builder in the existing CLI.
**Failure paths:** Invalid paths and malformed property lists are rejected without replacing existing files.
**Criterion:** AC-002: the plist preserves absolute paths and bounded restart behavior.

### cli/src/launch_agent/agent_control.rs
**Purpose:** Queries and controls the current user's launchd GUI service through launchctl.
**Feature:** macos-launch-agent
**Existing code checked:** `rg -n launchctl cli/src` shows no existing launchd service controller.
**Failure paths:** Missing GUI domains and failed subprocesses are reported without claiming a service is active.
**Criterion:** AC-004: registration uses the current user's GUI domain.
**Split justification:** Service control and plist creation are separate duties with different failure modes.

### cli/src/launch_agent/agent_command.rs
**Purpose:** Validates launch agent commands and coordinates preview, install, status, and removal.
**Feature:** macos-launch-agent
**Existing code checked:** `rg -n read_settings_and_bytes cli/src` identifies the existing validated settings reader.
**Failure paths:** Invalid arguments, unsafe existing files, and partial service failures return clear errors without altering settings.
**Criterion:** AC-001: installation previews and checks its inputs.
**Split justification:** Command orchestration is separate from plist encoding and launchd control.
