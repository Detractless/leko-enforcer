This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### voice/stt_lifecycle.py
**Purpose:** Lazy-load, page-cache warm, and idle-unload the STT model with configurable timeout.
**Feature:** voice-streaming-and-cache
**Existing code checked:** `grep -rn -e get_stt -e _stt_model -e load_model voice/` shows only assistant.py's inline lazy load with no warm cache or unload.
**Failure paths:** Missing model file logs a warning and returns None; idle unload skipped if transcription in progress; warm cache failure does not block startup.
**Criterion:** AC-001: Model loads lazily on first transcription request, not at startup; startup completes without loading the STT model.

### voice/pipelined_chunker.py
**Purpose:** Transcribe earlier audio windows while recording continues, finalize all windows into one transcript.
**Feature:** voice-streaming-and-cache
**Existing code checked:** `grep -rn -e chunk -e prechunk -e pipelin voice/` shows only capture-gate audio chunking (capture_gate.py), no STT transcription chunking.
**Failure paths:** Empty audio returns empty string; cancel resets pipeline and discards partials; shortfall falls back to batch transcription.
**Criterion:** AC-004: A recording longer than the chunk window (default 30s) produces intermediate transcription results for completed windows while recording is still active.
