This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### voice/routing/native_cli.py
**Purpose:** Build canonical native CLI argument lists and parse the stable JSON output for voice routing.
**Feature:** native-leko-voice-routing
**Existing code checked:** `git ls-files voice/routing` lists the four tracked routing files that map intents to the removed legacy CLI.
**Failure paths:** An unknown tool returns a usage error rather than a legacy command, a non-zero CLI result is surfaced plainly, and malformed JSON is reported instead of being read as text.
**Criterion:** AC-001: every voice tool and CLI argument list uses the ten canonical commands and kebab-case flags.

### voice/routing/canonical_speech.py
**Purpose:** Produce exact Title Case canonical speech and the fixed refusal for planned features.
**Feature:** native-leko-voice-routing
**Existing code checked:** `git ls-files voice/normalization` lists the three protected verbalizer files that this module must not edit.
**Failure paths:** Empty or missing status data gives a plain empty or error state, a planned feature returns the fixed line with no CLI call, and a seal refusal is never spoken as a completed edit.
**Criterion:** AC-004: confirmations, status readouts and errors speak exact Title Case canonical names.
