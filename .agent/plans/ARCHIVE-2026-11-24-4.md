# Active plan: one "### <path>" entry per new code file (format: .agent/plans/TEMPLATE.md)
<!-- contract-required -->
This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### core/src/services/runner.rs
**Purpose:** Run pinned add-ons over the challenge IPC protocol with a timeout and strict reply checks.
**Feature:** native-leko-addon-runner
**Existing code checked:** `git ls-files core/src/services` lists the verifier hook and nonce guard this runner plugs into.
**Failure paths:** A wrong challenge id, reused nonce, malformed reply, non-zero exit or timeout returns an error that the hook turns into NotSatisfied.
**Criterion:** AC-002: the challenge protocol requires matching challenge id, unused nonce and satisfied status.

### core/src/services/recipe.rs
**Purpose:** Parse and run JSON and TOML no-code recipes for command, HTTP JSON and prompt checks.
**Feature:** native-leko-addon-runner
**Existing code checked:** `git ls-files core/src/services` lists the runner and verifier service files this recipe module extends.
**Failure paths:** A malformed recipe, a failed command or a missing HTTP field returns an error instead of a satisfied result.
**Criterion:** AC-008: all three built-in recipes run without compiled add-on code.

### core/src/services/snapshot_pin.rs
**Purpose:** Hash an add-on bundle and copy it into a configurable read-only quarantine snapshot.
**Feature:** native-leko-addon-runner
**Existing code checked:** `git ls-files core/src/io` lists the existing snapshot store this pinning module hardens.
**Failure paths:** A missing manifest, hash mismatch, unknown version or interrupted copy leaves the previous snapshot readable and reports the path.
**Criterion:** AC-003: pin copies a hashed bundle into the snapshot root.

### cli/src/services/addon.rs
**Purpose:** Expose canonical CLI commands to pin, list and verify add-ons and check pinned results.
**Feature:** native-leko-addon-runner
**Existing code checked:** `git ls-files cli/src/services` lists the report writers this add-on service joins.
**Failure paths:** A missing add-on id or snapshot root prints usage with a non-zero code, and repeated pins are idempotent.
**Criterion:** AC-009: canonical add-on commands and stable JSON output.
