This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### core/src/error.rs
**Purpose:** Define the shared error type that turns load failures into plain, named messages.
**Feature:** native-leko-rewrite
**Existing code checked:** `git ls-files core/src` lists the tracked files under core/src, showing the legacy source layout this native file replaces.

**Criterion:** AC-010: the native JSON store reports a missing, empty or corrupt store plainly and never silently overwrites it.
