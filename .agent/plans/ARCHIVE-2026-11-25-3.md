This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### ui/pill/main.swift
**Purpose:** Dispatch the pill between a headless JSON state-machine mode and the AppKit panel.
**Feature:** native-leko-voice-pill
**Existing code checked:** `git ls-files ui` lists the WebView circle crate this binary replaces.
**Failure paths:** A malformed headless event is ignored, and the GUI path never activates another app.
**Criterion:** AC-010: the pill builds with swiftc and AppKit without new Rust dependencies.

### ui/pill/PillState.swift
**Purpose:** Hold the deterministic idle, blocked, dictation, speaking and timer state machine.
**Feature:** native-leko-voice-pill
**Existing code checked:** `git ls-files tests/ui` lists circle-state tests this state model replaces.
**Failure paths:** A blocked flash returns to idle after two seconds, and a timer is cleared when its pass ends.
**Criterion:** AC-004: dictation states flow from hold to idle.

### ui/pill/EventBridge.swift
**Purpose:** Read atomic enforcement events and pill config and write pill actions back to the voice bridge.
**Feature:** native-leko-voice-pill
**Existing code checked:** `git ls-files voice/core` lists the UI bridge this event file replaces on the IPC side.
**Failure paths:** A truncated event file is ignored, and config values fall back to dark and bottom-center when absent.
**Criterion:** AC-009: the atomic event file bridge is deterministic.

### ui/pill/PillPanel.swift
**Purpose:** Render the monochrome non-activating always-on-top NSPanel for the pill.
**Feature:** native-leko-voice-pill
**Existing code checked:** `git ls-files ui` lists the large WebView window this panel replaces.
**Failure paths:** The panel never takes focus, and no accent color, dot or chevron is drawn.
**Criterion:** AC-006: the panel is non-activating and always on top.
