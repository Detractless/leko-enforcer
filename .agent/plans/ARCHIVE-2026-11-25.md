This project builds new features under contracts (.agent/contracts/<feature>.md). A new code file needs an entry here whose
Feature has an open contract and whose Criterion names one of that contract's acceptance criteria.

### cli/src/services/os_executor.rs
**Purpose:** Define the injected OS executor trait, a deterministic mock and the real platform adapter.
**Feature:** native-leko-enforcer-loop
**Existing code checked:** `git ls-files platform/macos/src` lists the running, terminate and device action adapters this trait wraps.
**Failure paths:** A mock returns scripted observations and records actions only, and an unavailable device action is reported as an error rather than a panic.
**Criterion:** AC-005: mock executors never touch the real machine.

### cli/src/services/enforcement_loop.rs
**Purpose:** Run the continuous enforcement loop that applies native decisions to apps, browsers and device actions.
**Feature:** native-leko-enforcer-loop
**Existing code checked:** `git ls-files cli/src/services` lists the one-shot enforce function this loop replaces.
**Failure paths:** A corrupt store keeps the last valid state, a dry run makes no OS calls, and a shutdown request ends the loop cleanly.
**Criterion:** AC-001: the loop reloads the store on every tick.
